# PDF2MD 前置区域识别级联

## 目标

PDF2MD 将“文字识别”和“文档区域识别”分开处理。OCR 负责字符，区域识别负责判断封面、版权页、前言、摘要、目录、图目录、表目录、缩略语、符号表以及正文起点。目录重建仍以正文中的真实 Markdown 标题和图表题注为最终真值，分类器不能凭空创建链接目标。

首版不再增加一个大型视觉模型。MinerU 已经运行 PP-DocLayoutV2，并为每个布局框生成 `label`、`score`、`bbox` 和阅读顺序。PDF2MD 保留这些信号，再按以下顺序决策：

1. 高置信规则锁定可证明的结果，例如精确的中英文目录标题、可靠 INDEX 块、明确正文标题和页眉页脚否决。
2. 布局模型头聚合 PP-DocLayoutV2 的检测框、位置、面积、分数和阅读顺序，输出按类别校准的概率。
3. 只有布局阶段不确定、冲突或分布外时，才读取同一次转换已经得到的 OCR/原生文本，运行轻量字符 n-gram 文本模型；不会重新 OCR。
4. 相邻页序列只提供弱约束。最终概率、类别间隔或分布外检查仍不合格时返回 `abstain`/`needs_review`，不修改 Markdown。

## 置信度语义

- 规则的 `rule_strength` 是可解释证据强度，不是统计概率。
- 模型的 `calibrated_probability` 必须由独立校准集得到。
- 每个类别使用独立的接受阈值与 top-1/top-2 margin；不能用一个全局阈值。
- “检测到候选区域”和“允许自动改写”使用不同阈值。目录、图表目录和正文起点属于破坏性类别，自动改写阈值更高。
- 发布门槛以精度优先：破坏性类别的自动动作目标 precision 至少 99%，并单独统计误删前置内容。

## 缓存分层

昂贵的 PDF/OCR 结果继续保存在 `raw/cache/content-lists/`，其键不随区域模型升级而变化。区域识别报告保存到独立缓存：

```text
raw/cache/front-regions/<selection-key>/<classifier-fingerprint>.json
```

指纹包含规则版本、布局模型、文本模型、校准参数和阈值摘要。模型升级只重新分类已有 content-list，不会重跑 OCR。`raw/cache/front-regions-v1.json` 是供现有目录整理器读取的兼容投影。

## V2 报告

`pdf2md.front-regions.v2` 报告记录：

- 输入 content-list 的 SHA-256 和物理页选择；
- 分类器、规则、模型、校准与阈值指纹；
- 各阶段调用次数和耗时；
- 每页的候选类别、接受状态、决策来源、规则证据、校准概率和拒判原因；
- 经过边界、数值和大小校验的布局块元数据；
- 可追溯的导航块。只有 `accepted=true` 的安全结果会投影到 V1。

## 数据与标注

仓库只提交来源清单和页级标签，不提交下载 PDF、OCR 文本、页面图像或模型缓存。页级标注使用物理 PDF 页码，并绑定源文件 SHA-256。训练数据分成三类：

1. 许可明确的可训练数据，可进入可发布权重；
2. 厂商手册、版权不明论文和用户文件，只用于本地回归评估；
3. 项目自己生成的合成前置页，用于补足稀有类别和验证流水线。

自动预标注只产生 `needs_review`。规则与正文反演可生成弱标签，但测试集和发布模型的校准集必须人工复核。训练、校准、测试按整份文档和模板来源切分，禁止同一 PDF 的页面跨集合泄漏。

## 训练顺序

1. 先训练布局检测结果之上的小型线性/DeepSets 头，而不是微调 PP-DocLayoutV2。
2. 再训练中英文共享的字符 2--5 gram 哈希文本模型，只处理低置信页面。
3. 用独立校准集做 temperature scaling，并按类别从 precision/coverage 曲线选择阈值。
4. 评估每类 precision/recall/F1、ECE、Brier、coverage-risk、正文边界误差、导航 span IoU、OCR 文本二判调用率和 CPU 延迟。
5. 只有误差分析证明大量真实目录根本没有任何 `content/index` 候选框时，才引入 PP-DocLayoutV2 检测头的专门训练实现。当前 MinerU 推理类不支持直接传入 labels 训练，不能把它误当成可微调的 Hugging Face 检测器。

## 安全边界

- 模型只能提供区域候选、顺序和块边界。
- 正向目录链接只能指向显式 `#`--`######` 标题或经过严格识别的图表题注。
- 同名/同编号目标无法唯一消歧时不建立链接。
- 部分页转换不得利用未选择页面的证据跨页推断。
- 低置信、损坏模型、NaN、未知标签、异常 bbox、模型缺失或规则冲突均安全降级，不得删除原文。
